# KYRO 🌟

> A modern, elegant, and animated perfume website built with a premium visual experience in mind.

## ✨ About

**KYRO** is a stylish perfume website focused on creating a clean and immersive browsing experience. It combines modern UI design, smooth animations, and bold visual elements to give the brand a distinctive and premium identity.

## 🚀 Features

* 🎨 Modern and minimal UI
* ✨ Smooth animations and transitions
* 🌟 Premium perfume-focused design
* 📱 Responsive layout
* ⚡ Fast and interactive user experience
* 🖥️ Clean and organized interface

## 🛠️ Built With

* HTML
* CSS
* JavaScript

## 🎯 Goal

The goal of KYRO is to create a visually engaging perfume website that feels modern, luxurious, and easy to navigate while showcasing the brand and its products.
